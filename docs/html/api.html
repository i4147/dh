dh.textutils

count_words

count_words(text: str) -> int

Count Unicode letter/number words, keeping internal apostrophes together.

Underscores, hyphens, and punctuation separate words. Numbers count as words. This is a lexical heuristic, not language-specific segmentation (e.g. an unspaced Chinese sentence is a single token).

levenshtein

levenshtein(left: str, right: str) -> int

Return unit-cost insertion/deletion/substitution distance between strings.

Comparisons are case-sensitive and operate on Unicode code points, not grapheme clusters. No normalization is implicit. Uses O(min(m, n)) memory and O(m*n) time; transpositions count as two edits.

text_distance

text_distance(left: str, right: str) -> float

Return Levenshtein distance divided by the longer string length.

The result lies in [0, 1]: zero means identical and one means maximally different. Two empty strings have distance zero. Case and Unicode behavior are the same as levenshtein; this is a distance, not a similarity score.

to_camel

to_camel(text: str, *, upper_first: bool = False) -> str

Convert words or identifiers to lowerCamelCase, or PascalCase if requested.

Uses to_snake boundary rules and normalizes acronyms (HTTPServer becomes httpServer). Empty or punctuation-only input returns an empty string.

to_snake

to_snake(text: str) -> str

Convert words or identifiers to lowercase snake_case.

Handles acronyms (HTTPServer -> http_server), Unicode case boundaries, punctuation separators, and digit runs (version2 -> version_2). Empty or punctuation-only input returns an empty string. No identifier validity is guaranteed (e.g. a leading number is retained).

word_frequencies

word_frequencies(text: str, *, case_sensitive: bool = False) -> collections.Counter[str]

Count words using count_words tokenization and optional case sensitivity.

By default Unicode casefold merges case variants. Tokens use NFC Unicode normalization and curly apostrophes are canonicalized to straight ones. Return a Counter, supporting most_common() and zero for missing words.
