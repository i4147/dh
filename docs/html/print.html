dh utilities

dh utilities

dh provides typed filesystem helpers, terminal formatting, text processing, and parallel task execution. Python 3.11 or newer is supported.

python -m pip install -e '.[dev,parallel]'

Rich and Loguru are installed as runtime dependencies. Joblib and tqdm are optional: install the parallel extra when using those backends/progress bars.

from dh import get_files, get_dirs

sources = get_files("src", ext=[".py"])
directories = list(get_dirs("src"))

Filesystem helpers are implemented in dh.fileutils. Existing imports from dh.pathutils still work and refer to the same functions. The package root also re-exports these helpers.

Pure-Python traversal

All standard traversal helpers use a shared os.scandir engine in fileutils. It uses cached DirEntry type metadata, prunes excluded subtrees before opening them, and uses an explicit stack to avoid recursive Python calls. It needs no native extensions and works on all supported Python versions.

Filesystem traversal

from pathlib import Path
from dh.fileutils import get_files, get_filez, get_dirs

rst_files = get_files(Path("docs"), ext=[".rst"], skip_dirs={"vendor"})
for script in get_filez("src", pyfiles=True, nobinary=True):
    print(script)

dirs = get_files("src", dirs_only=True)
assert dirs == sorted(get_dirs("src"))

Filtering contract

  • get_files returns a sorted list[Path]; get_filez returns an iterator.
  • ext=None and ext=[] disable suffix filtering. Leading dots are optional, matching is case-insensitive, and compound suffixes such as .tar.gz work.
  • Filters combine: ext=[".py"], pyfiles=True requires both conditions.
  • pyfiles=True accepts .py files (including empty files) and extensionless files whose first line is a Python shebang. It does not parse arbitrary text.
  • nobinary=True uses the package's extension/content-based binary classifier.
  • skip_dirs=None uses dh.const.SKIP_DIRS; a custom set replaces this set. Entries below matching directory components are excluded as well.
  • dirs_only=True ignores all file filters and includes the root directory, get_dirs delegates to this mode.
  • Hidden children, symlinks, and bytecode caches are omitted by the walker. Use skip_dirs=set() to include non-hidden cache/build directories.
  • A single file root can be filtered too. Missing roots and traversal errors raise OSError subclasses. Results remain relative if the input is relative.

The shared os.scandir engine is lazy: get_filez filters entries as they are visited without collecting the entire tree. Directory exclusions prune work before descent. Only one directory handle is open at a time; file-type checks use cached DirEntry metadata rather than additional Path.stat calls. An explicit stack avoids Python recursion limits. Directory mode can yield a directory before its children are visited; get_files sorts its final results.

Compatibility

dh.pathutils is a compatibility import layer, not a second implementation. get_pyfiles and get_nobinary delegate to the same filtering engine. Older helpers such as getfiles, walkfiles, get_files_scandir, and configurable walkers share this engine while retaining their specialized filtering/error semantics; use get_files for the new unified filtering interface.

Commands and terminal text

import sys
from dh import runcmd

code, stdout, stderr = runcmd(
    [sys.executable, "-c", "print('hello')"],
    show_output=False,
    timeout=5,
)
assert (code, stdout, stderr) == (0, "hello\n", "")

Commands use argument vectors without a shell. Standard input is disconnected; stdout and stderr are captured separately. show_output=True emits the cleaned streams after the process finishes, rather than streaming live output.

dh.utils.clean_terminal_transcript removes ANSI/OSC escapes, control characters, backspace artifacts, and carriage-return progress updates. It trims trailing whitespace, collapses long blank-line runs, and terminates nonempty output with a newline. runcmd preserves truly empty streams as "".

Failure diagnostics go through the same cleanup and emission path as normal output. The internal failure handler does not recursively execute another command just to report an error. Invalid empty commands raise ValueError; non-string arguments raise TypeError before subprocess execution.

Text utilities

dh.textutils offers dependency-free text helpers, also exported from dh.

from dh import (
    levenshtein, text_distance, count_words,
    to_camel, to_snake, word_frequencies,
)

assert levenshtein("kitten", "sitting") == 3
assert text_distance("kitten", "sitting") == 3 / 7
assert count_words("Don't stop, keep going!") == 4
assert to_snake("HTTPServer") == "http_server"
assert to_camel("hello_world") == "helloWorld"
assert to_camel("hello_world", upper_first=True) == "HelloWorld"
assert word_frequencies("Hello hello world").most_common(1) == [("hello", 2)]

Distance

levenshtein(left, right) returns the minimum number of unit-cost insertions, deletions, and substitutions. It is case-sensitive, with no implicit Unicode normalization. It operates on Unicode code points, not grapheme clusters, and transpositions cost two edits. Time is O(m × n); auxiliary memory is O(min(m, n)).

text_distance divides that distance by the longer input length, producing a number between zero (identical) and one (maximally different). Two empty strings have distance zero. It is not a similarity score; use 1 - text_distance(a, b) if a normalized similarity is desired. This length-normalized score does not necessarily obey the triangle inequality; raw Levenshtein distance does.

Words and frequencies

count_words counts Unicode letter/number runs, preserving internal straight or curly apostrophes in contractions. Numbers count as words; underscores, hyphens, and other punctuation separate words. Input is NFC-normalized before splitting. This is a lexical heuristic: it does not perform language-specific segmentation, so an unspaced Chinese sentence counts as one token.

word_frequencies returns collections.Counter[str] using the same tokens. By default Unicode casefold() merges variants such as Straße and STRASSE. Use case_sensitive=True to preserve case. Curly apostrophes normalize to straight ones in either mode. Missing words have count zero; most_common() provides ranked counts. Empty input returns an empty Counter.

Case conversion

to_snake and to_camel split punctuation, whitespace, underscores, lower-to-upper case transitions, acronym endings, and digit runs. Acronyms normalize to ordinary word casing: XMLHttpRequest becomes xml_http_request or xmlHttpRequest. version2HTTPServer becomes version_2_http_server or version2HttpServer. Unicode letter casing is supported. to_camel(..., upper_first=True) produces PascalCase instead of lowerCamelCase. Empty or punctuation-only input returns "". These converters do not validate Python identifiers; leading numbers remain.

Other utilities

Text and hashing

get_sha256(path) streams a file into a SHA-256 digest. has_doc(code) detects Python comments or docstrings. is_valid_url accepts plausible HTTP/HTTPS URLs and rejects missing input. slugify creates ASCII slugs; tokenize_text splits identifiers into words and numeric tokens. cube_rgb expects an xterm color-cube index in the inclusive range 16–231.

Terminal formatting

colored returns styled text; cprint prints it. Both accept foreground, background, and style attributes. Explicit overrides and terminal environment settings determine whether ANSI color sequences are emitted.

Parallel execution

from dh import Method, mpf, values, failures

outcomes = mpf(abs, [-2, -1, 0], method=Method.THREAD, progress=None)
assert values(outcomes) == [2, 1, 0]
assert failures(outcomes) == []

Outcomes contain input indexes, items, results, and error information. Thread execution supports non-picklable callables; process backends require picklable functions and inputs. Put process-based calls behind an if __name__ == "__main__" guard. Interpreter pools require Python 3.14+; unavailable methods raise MethodUnavailableError. Python 3.11 uses equivalent TypeVar/Generic type syntax, without requiring newer parser features.

For file-specific multiprocessing, process_files yields (path, result) pairs; worker exceptions become ERROR: strings. FileWalkerConfig supports depth, hidden-file, pattern, and symlink controls for the legacy configurable walker.

Constants and file classification

Extension sets are immutable frozenset[str] values, normalized to lowercase with leading dots. TEXT_EXTENSIONS and BINARY_EXTENSIONS are disjoint. is_text_file matches suffixes case-insensitively and samples content when no unambiguous extension or text basename hint exists. These hints are convenience heuristics, not file-format validation or a security boundary.

Corrections

  • Compiled .class/.pyc files and Office .doc/.docx containers are binary.
  • Textual .ass, .tsv, .pem, .xbm, .xpm, .afm, .bdf, .dae, and .dxf files no longer have binary-only hints.
  • .ts (TypeScript/MPEG transport stream), .plist (XML/binary plist), .obj, .stl, .fbx, .vtk, .pot, .mod, .pth, certificate files, and portable bitmap formats have ambiguous representations. Neither set forces their type; they use the existing content sampler. UTF-16 and unusual encodings can still be misclassified by that heuristic.
  • Unsupported wildcard-looking entries and questionable suffixes were removed from the binary allowlist; unknown extensions use content sampling instead.
  • Exact text names such as README, Makefile, .gitignore, and .env belong in TEXT_FILENAMES, not extension tables. The classifier checks both.

Other values

STDLIB uses the current interpreter's sys.stdlib_module_names, removing the stale Python 2/platform-specific inventory. PY_KEYWORDS retains its historical role as an identifier vocabulary (keywords, soft keywords, builtins, self, and cls), but derives these names from the current interpreter instead of a stale list. It is not a strict keyword-only set; use keyword.iskeyword for that.

CSS named colors include the CSS3 set plus rebeccapurple, with corrected aliceblue and midnightblue RGB values. ANSI yellow and dim/grey escape strings are corrected. Duplicate MIME keys are removed, and OpenType uses font/otf. MIME reverse aliases remain intentionally many-to-one for compatibility.

Archive/audio/video categories include common omitted formats; font/image/document categories no longer include unrelated generic binary, audio-only, or database suffixes. Category membership describes the kind of file, not whether it is text.

Default SKIP_DIRS excludes generated output, environments, and tool metadata. It no longer excludes ordinary source/package names (numpy, pandas, pip, scipy, mypy, cython) or .github. Hidden directories are still omitted by get_files; lower-level legacy walkers can include hidden files. Passing an explicit skip set replaces the defaults rather than extending them.

Count Unicode letter/number words, keeping internal apostrophes together.

levenshtein(left: str, right: str) -> int

Return unit-cost insertion/deletion/substitution distance between strings.

Comparisons are case-sensitive and operate on Unicode code points, not grapheme clusters. No normalization is implicit. Uses O(min(m, n)) memory and O(m*n) time; transpositions count as two edits.

The result lies in [0, 1]: zero means identical and one means maximally different. Two empty strings have distance zero. Case and Unicode behavior are the same as levenshtein; this is a distance, not a similarity score.
